## 付録A：カスタマイズガイド

### A.1 本付録について

本付録は、Marcanus世界を使用して物語を作る際に「何を変えてよいか」「何を変えてはいけないか」「どこに自由な余白があるか」を明示するためのガイドである。

この世界はオープンソースの設定資料として設計されている。使用者は本編の制度を「そのまま使う」こともできるし、「改変して使う」こともできる。ただし、根幹を崩すと制度間の連関が破綻するため、「変えてはいけない部分」を明確に示しておく必要がある。

|項目|内容|
|---|---|
|目的|使用者が安全に改変できる範囲を明示する|
|前提|根幹を維持すれば、それ以外は全て自由|
|推奨|まず根幹を理解し、その上で自分の物語に必要な改変を加える|

---

### A.2 変えてはいけない根幹

以下の要素は、この世界の制度間連関の基盤であり、変更すると全体が破綻する。

|根幹|理由|
|---|---|
|政教一致（王＝教皇）|全ての正当化の起点。これを分離すると「王に逆らう＝神に逆らう」が崩壊し、反乱の心理的コストが下がる|
|衆愚教育（識字率は高いが思考力を育てない）|全制度の成立条件。民衆が「疑問を持たない」ことが前提|
|アンチ・ハンムラビ（過剰報復の正当化）|相互監視装置。これがないと連帯が成立し、反乱が可能になる|
|定期投薬の義務化|国家への依存と従順さの物理的保証|
|ロックダウン（3年に一度）|「国家がないと死ぬ」の定期的刷り込み|
|奴隷制度の3年任期制|「希望を残す」設計。世襲にすると別の社会になる|
|三聖女が常に三人|ノルンとの宗教的対応。数を変えると宗教体系が崩れる|
|秘密の自己完結（真実を知る者がゼロ）|Marcanusの核心。これを崩すと世界の本質が変わる|

---

### A.3 自由に変更できる要素

以下は明示的に「使用者が設計する」ことを前提とした要素である。

#### 制度の詳細

| 要素                      | 選択肢の例                   |
| ----------------------- | ----------------------- |
| 宗教の名称・経典・礼拝形式           | 一神教でも多神教でも可。名前は自由       |
| 教育期間・教育施設の形態            | 寺子屋型、教会付属型、集団収容型        |
| 人権の具体的保障内容              | 居住権・財産権・婚姻権など           |
| 貴族の爵位体系                 | 付録C参照。7モデルから選択または独自設計   |
| 軍の正式名称・規模・編成            | 使用者が命名・設計               |
| 奴隷への暴力の程度               | 物語のトーンに応じて調整            |
| 死体処理施設の所在地              | 都市内・郊外・地下など             |
| コレストウイルスの症状・感染経路        | 不明のまま残すことも可能            |
| 毒殺の即効性                  | 「刺した瞬間に死ぬ」〜「数分で意識喪失」の範囲 |
| 聖女の用済み後の民衆への説明          | 「神の御許に還った」等             |
| 風俗施設の内部階層               | 付録Cの吉原遊廓型を参照            |
| 老齢者の扱い・妊婦の猶予・子どもの労働開始年齢 | 物語の方向性に応じて              |

#### 世界の拡張

|要素|選択肢の例|
|---|---|
|他国の存在と詳細|軍の対外機能を描くなら必要。設計は完全に自由|
|地理・気候・地形|未定義。物語の舞台に合わせて自由に設計|
|技術水準の細部|中世ヨーロッパの範囲内であれば自由|
|言語・文字体系|未定義|
|通貨・経済構造|未定義|
|動植物・食文化|未定義|

### A.4 時間軸の自由

この世界は王暦1540年（物語開始時点）だけが舞台ではない。使用者は以下の時間軸のいずれにも物語を配置できる。

|時間軸|内容|使い方|
|---|---|---|
|初代王暦（500年間）|先住民族の時代。現王朝が末裔を自称する対象|「本来の歴史」を描く物語|
|君暦・帝暦|水増しされた王朝の実像|権力闘争・法典の変遷を描く|
|皇暦（天見一族）|シャーマニズム＋偶像崇拝＋呪術の支配|崩壊劇・暴露の過程を描く|
|秘匿された600年（爽暦・真暦・冠暦）|存在を抹消された民族の時代|「消された側」の視点で描く|
|現王朝成立〜パンデミック前（王暦1〜1339年）|捏造の定着・制度の漸進的構築|支配の起源を描く|
|パンデミック（王暦1340年）|コレストウイルスの発生と社会崩壊|災厄もの・サバイバル|
|200年間の変質（王暦1340〜1540年）|緊急対応が支配装置に変わっていく過程|制度の変質を描く。「善意が悪意に変わる」物語|
|王暦1540年（物語開始時点）|全制度が完成し噛み合っている状態|本編の想定する主要舞台|
|王暦1540年以降（未来）|この社会がどう変化するか、崩壊するか|革命もの・終末もの・希望の物語|

### A.5 パラレルとしての利用

Marcanus世界は「唯一の正史」を持たない。使用者は以下のような利用が可能である。

|利用形態|内容|
|---|---|
|正史準拠|本編の設定をそのまま使い、王暦1540年を舞台にする|
|時間軸の移動|別の時代を舞台にする（上記A.4参照）|
|パラレルワールド|「もしこの制度がなかったら」「もし天見一族が崩壊しなかったら」等のif世界を構築する|
|部分的採用|一部の制度だけを取り出して、別の世界観に組み込む|
|設定の分岐|本編の特定時点から歴史が分岐した世界を描く|
|他作品との融合|併用可能な資料（オムンティギア設定資料等）と組み合わせる|

これらの利用形態に優劣はない。「正しい使い方」は存在しない。使用者の物語が面白ければ、それが正解である。

### A.6 改変時のチェックリスト

設定を改変する際、以下の質問に答えることで整合性の崩壊を防げる。

|チェック項目|確認内容|
|---|---|
|1. 根幹に触れていないか？|A.2の8項目に抵触していないか確認|
|2. 連関する制度は何か？|変更した制度が他のどの制度と接続しているか確認（第1章 1.7参照）|
|3. 連関先に矛盾が生じないか？|接続先の制度が変更後も機能するか確認|
|4. 民衆の認識は変わるか？|変更が「民衆に見える世界」に影響するか確認|
|5. 宗教的正当化は維持されるか？|変更後も「神の意志」で正当化できる構造か確認|
|6. 衆愚教育との整合性はあるか？|変更が「考えない民衆」の前提を崩さないか確認|
|7. 秘密保持構造に影響しないか？|変更によって「真実を知る者がゼロ」が崩れないか確認|

#### チェックの実例

|改変案|チェック結果|
|---|---|
|「奴隷の任期を5年に変更したい」|根幹（3年）に触れるが、「期限付きである」こと自体が本質。5年でも制度の論理は維持可能。ただし「希望」の心理設計が弱まる可能性がある|
|「魔法を追加したい」|根幹には直接触れないが、中世技術水準の制約が崩れる。死体処理・疫病対策・秘密保持の全てに影響。大規模な再設計が必要|
|「王と教皇を別人にしたい」|根幹に直接抵触。政教一致の解除は全制度の正当化基盤を喪失させる。非推奨|
|「三聖女を五聖女にしたい」|根幹に抵触。ノルンとの対応が崩れ、宗教体系の再設計が必要。やるなら宗教を丸ごと再構築する覚悟で|
|「他国の詳細を追加したい」|根幹に触れない。完全に自由。軍制度との接続を考慮すればよい|

### A.7 根幹を変えたい場合

根幹を変えること自体は禁止されていない。Creative Commonsライセンスにより改変は自由である。

ただし根幹を変える場合、「なぜこの世界がこうなっているか」の因果関係が全て組み替わることを理解した上で行う必要がある。以下に目安を示す。

|根幹の変更|影響範囲|再設計が必要な章|
|---|---|---|
|政教一致の解除|全制度の正当化基盤が消失|全章|
|衆愚教育の廃止|民衆が「疑問を持てる」ようになる|第5〜13章全て|
|アンチ・ハンムラビの撤廃|相互監視が崩壊。連帯が可能に|第5・7・9・11・12・13章|
|定期投薬の廃止|国家依存の物理的根拠が消失|第7・8章|
|ロックダウンの廃止|国家リズムへの依存が消失|第8章、社会構造全般|
|奴隷の世襲化|「希望を残す」設計が消滅。カースト社会になる|第7・9章|
|真実を知る者の配置|Marcanusの核心が変化。「空虚」が「秘匿」になる|第2・13章|
